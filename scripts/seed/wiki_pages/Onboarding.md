# Onboarding

1. Clone the harness, then run `scripts/seed/seed.py repos --apply` to clone ingest, dbt and infra next to it.
2. Read `AGENTS.md`: every change has a ticket, and agents never approve, answer or close.
3. Start with a small ticket such as DEMO-0001 to see the gates; DEMO-0030 is the open docs task.
